# SYNCORE calc

Сайт: [syncore54.ru](https://syncore54.ru)

Линейка калькуляторов **SYNCORE**. Автор: [Павел Исламов](https://pavelislamov.ru/) — портфолио, продукты и контакты.

Инженерные калькуляторы для производства и ЧПУ. Рабочие модули: **фрезерование**, **токарка**, **метрическая резьба**, **лазерная резка**.

Принцип: материал → инструмент / источник → режимы. Станок по умолчанию, ограничения — по желанию. **Сервис бесплатный**, без регистрации.

Значения режимов — **справочные диапазоны**, не гарантированный паспортный режим конкретного инструмента, резонатора или станка.

## Посещаемость

Анонимный счётчик (без имён и IP). Страница **не в меню** — откройте `/usage` и введите пароль из `STATS_TOKEN` в `.env` (файл не коммитится). Данные: `.data/telemetry.json` при `npm run dev` / `npm run preview`.

На статическом хостинге этот API не работает — тогда задайте `VITE_TELEMETRY_URL` на свой коллектор или подключите Plausible / Umami.

## Публикация: GitHub + Beget (как портфолио)

[pavelislamov.ru](https://pavelislamov.ru/) уже работает так: **файлы — GitHub Pages**, **DNS — Beget** (`ns1.beget.ru` / `ns2.beget.ru`). Калькулятор на [syncore54.ru](https://syncore54.ru) лучше выложить так же.

### 1. GitHub

1. Создайте репозиторий на том же аккаунте, что и портфолио, и запушьте этот проект.
2. Settings → Pages: Source = **GitHub Actions**.
3. Settings → Pages → Custom domain: `syncore54.ru`, включите **Enforce HTTPS** после проверки DNS.
4. Workflow `.github/workflows/pages.yml` собирает `dist/` и выкладывает Pages. Для SPA копируется `404.html` (прямой заход на `/milling`).

В `public/CNAME` уже указан `syncore54.ru`.

### 2. DNS в панели Beget

Раздел **Домены** → DNS-записи для `syncore54.ru` (те же A, что у портфолио):

| Имя | Тип | Значение |
| --- | --- | --- |
| `@` | A | `185.199.108.153` |
| `@` | A | `185.199.109.153` |
| `@` | A | `185.199.110.153` |
| `@` | A | `185.199.111.153` |
| `www` | CNAME | `ВАШ-ЛОГИН.github.io.` |

Логин GitHub тот же, что у `www.pavelislamov.ru` (`….github.io`). Не прикрепляйте `syncore54.ru` к сайту в разделе «Сайты» Beget — иначе панель перезапишет A-записи на IP хостинга и Pages перестанет открываться.

SSL выдаёт GitHub, не Let’s Encrypt в Beget.

### Другой вариант: файлы на хостинге Beget

Если хотите хранить калькулятор в `public_html` на Beget (не Pages):

1. В [Сайты](https://beget.com/ru/kb/manual/sajty) создайте сайт, прикрепите `syncore54.ru`.
2. Залейте содержимое `dist/` в `public_html` (файловый менеджер или FTP). Файл `.htaccess` уже в сборке — Apache отдаст SPA-маршруты.
3. В настройках домена включите редирект на HTTPS.

Счётчик `/usage` на чистой статике (и Pages, и `public_html`) не работает — нужен `VITE_TELEMETRY_URL` или Plausible / Umami.


## Что умеет сейчас

- Фрезерование: хобби 0.8 / 1.5 / 2.2 кВт и промышленный станок; S, F (XY) и Fz (врезание по Z); настройка D, L, r, угла
- Токарка: точение, торец, расточка, канавка, отрезка, сверление, пластины ISO
- Метрическая резьба M3–M30, отверстие под резьбу, подача = шаг
- Лазер: волокно и CO₂, толщина листа, газ, фокус, пробивка и настройки слоя
- Справочники материалов (включая чугун) и инструмента
- История и избранное в браузере

## Формулы

- Фрезерование: `n = (Vc × 1000) / (π × D)`, `Vf = n × z × fz`, `Vf_z = Vf × k_z`
- Точение: `Vf = n × f`, `P = (kc × ap × f × Vc) / (60 × 10³ × η)`
- Резьба: `d1 ≈ D − P`, `H1 = 0.54127 × P`, `f = P`
- Лазер: `V = V₁₅₀₀ × (P / 1500)^0.65 × k_кач`, `v = Vf / 60`, `T = L / Vf`

## Структура

- `src/engine` — расчёты без React
- `src/data` — материалы, инструмент, станки, лазерные таблицы, формулы
- `src/pages` — маршруты `/milling`, `/turning`, `/laser`, …
- `src/services` — хранилище и заготовки entitlements / Supabase

Секреты не хранятся в репозитории. Шаблон: `.env.example`.
