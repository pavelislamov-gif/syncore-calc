# SYNCORE calc

Линейка калькуляторов **SYNCORE**. Логотип: `public/logo.png`.

Инженерные калькуляторы для производства и ЧПУ. Рабочие модули: **фрезерование**, **токарка**, **метрическая резьба**, **лазерная резка**.

Принцип: материал → инструмент / источник → режимы. Станок по умолчанию, ограничения — по желанию.

Значения режимов — **справочные диапазоны**, не гарантированный паспортный режим конкретного инструмента, резонатора или станка.

## Что умеет сейчас

- Фрезерование: хобби 0.8 / 1.5 / 2.2 кВт и промышленный станок; S, F (XY) и Fz (врезание по Z); настройка D, L, r, угла
- Токарка: точение, торец, расточка, канавка, отрезка, сверление, пластины ISO
- Метрическая резьба M3–M30, отверстие под резьбу, подача = шаг
- Лазер: волокно и CO₂, толщина листа, газ, фокус, пробивка и настройки слоя
- Справочники материалов (включая чугун) и инструмента
- История и избранное в браузере

## Формулы

- Фрезерование: `n = (Vc × 1000) / (π × D)`, `Vf = n × z × fz`, `Vf_z = Vf × k_z`
- Точение: `Vf = n × f`, `P = (kc × ap × f × Vc) / (60 × 10³ × η)`
- Резьба: `d1 ≈ D − P`, `H1 = 0.54127 × P`, `f = P`
- Лазер: `V = V₁₅₀₀ × (P / 1500)^0.65 × k_кач`, `v = Vf / 60`, `T = L / Vf`

## Структура

- `src/engine` — расчёты без React
- `src/data` — материалы, инструмент, станки, лазерные таблицы, формулы
- `src/pages` — маршруты `/milling`, `/turning`, `/laser`, …
- `src/services` — хранилище и заготовки entitlements / Supabase

Секреты не хранятся в репозитории. Шаблон: `.env.example`.
