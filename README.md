# TechCalc

Инженерные калькуляторы для производства и ЧПУ. Первый рабочий модуль — **фрезерование**.

Принцип: выбор материала и инструмента → параметры станка → автоматический расчёт → понятный результат и проверка ограничений.

Значения режимов — **справочные диапазоны**, не гарантированный паспортный режим конкретного инструмента или станка.

## Запуск

```bash
npm install
npm run dev
```

Приложение: [http://127.0.0.1:4521](http://127.0.0.1:4521)

```bash
npm run test
npm run build
```

## Что умеет сейчас (этап 1)

- Главная страница и быстрый расчёт
- Фрезерование: хоббийный / промышленный станок
- Автоматический и ручной подбор Vc, fz, ap, ae
- Обороты, минутная подача, мощность (оценка)
- Проверка лимитов станка
- Справочник материалов и инструмента
- История и избранное в браузере (localStorage)
- Архитектура FREE/PRO без платежей

## Формулы

- `n = (Vc × 1000) / (π × D)`
- `Vf = n × z × fz`
- `Vc = (π × D × n) / 1000`
- `P = (ap × ae × Vf × kc) / (60 × 10^6 × η)` — ориентировочная мощность

## Структура

- `src/engine` — расчёты без React
- `src/data` — материалы, инструмент, станки, формулы
- `src/pages` — маршруты `/milling`, `/turning`, `/laser`, …
- `src/services` — хранилище и заготовки entitlements / Supabase

Секреты не хранятся в репозитории. Шаблон: `.env.example`.
